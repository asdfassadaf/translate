# Dumbrava Translate — телефон

Живой перевод речи в наушники: телефон слушает собеседника, Gemini 3.5 Live Translate переводит, перевод звучит в наушниках, на экране — субтитры.

**Открыть:** https://asdfassadaf.github.io/translate/

1. Откройте ссылку в Chrome на Android.
2. Вставьте свой API-ключ Gemini (хранится только в этом телефоне).
3. Меню Chrome → «Установить приложение» / «Добавить на главный экран».
4. Наденьте наушники и нажмите «Слушать».
